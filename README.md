# 🎱 Amigos do Bilhar

App de campeonatos de sinuca — funciona no celular e no computador, e pode ser instalado como app (PWA).

## Recursos
- Cadastro de jogadores (um por vez ou vários de uma vez)
- **Mata-mata**: sorteio automático, adicionar/remover chaves, arrastar nomes entre posições e para a próxima fase, ou tocar no vencedor para ele avançar sozinho
- **Pontos corridos**: tabela de rodadas (todos contra todos, com opção ida e volta), placar opcional e classificação automática
- Animação de sorteio e comemoração do campeão
- Backup/restauração dos dados para levar para outro aparelho
- Funciona offline depois do primeiro acesso

Os dados ficam salvos no próprio navegador do aparelho.
